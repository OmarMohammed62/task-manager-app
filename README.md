Task Manager App

A responsive Task Manager application built using HTML5, CSS3, and JavaScript.

Features

- Add new tasks.
- Edit existing tasks.
- Delete tasks.
- Mark tasks as completed.
- Search tasks in real time.
- Filter tasks by status (All, Completed, Pending).
- Display task statistics.
- Save tasks using Local Storage.

Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
